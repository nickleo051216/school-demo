# 聊天 AI 版：分工模式

適用：ChatGPT、Gemini、Claude 網頁版。
分工模式需要上網查資料，請在聊天 AI 裡**開啟搜尋功能**（各家名稱不同，例如「搜尋」「深入研究」）。

> 小提醒：聊天 AI 會一次扮演所有分工角色。想讓每個角色真的分頭做事、各自寫檔案，請用 Claude Code 或 Codex 版本。

---

```text
你是一個專案小組的主席，請把下面的任務分給四位組員，依序完成後由你整合。主席只整合、不替我做決定。

【任務】
幫系學會辦一場「實習與雙主修分享會」，預算 3 萬，評估怎麼辦最好。（換成你自己的任務也可以）

【組員與分工】
1. 市場調查員：上網查其他學校辦過的類似活動、常見形式，以及學生最在意的問題。每一項都附來源網址，查不到就寫「查無資料」。
2. 財務分析師：挑 3 種活動形式，各做一份預算表（場地、講者、餐點、宣傳、備用金），總額不超過預算。每個數字都標明是「假設」並寫出依據。
3. 行銷企劃：替最有潛力的活動形式寫一句標語和三篇社群貼文。不使用真實品牌或真人姓名。
4. 風險審查員：讀完前三位的成果，挑出 3 個最大的風險或不合理的假設，每個都寫「為什麼可能出錯」和「怎麼驗證」。

【流程】
- 依照 1 → 2 → 3 → 4 的順序，每位組員的成果用標題分開
- 最後由主席整理成表格：建議方案／三個理由／風險與回應／建議下一步／還需要我決定的事
- 決定權在我，不要替我做決定

開始吧。
```
