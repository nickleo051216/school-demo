# 聊天 AI 版：討論模式

適用：ChatGPT、Gemini、Claude 網頁版（免費版即可）。
用法：複製下面整段，把 `【】` 裡的內容換成你的，貼到**新對話**。

> 小提醒：聊天 AI 是「一個 AI 分飾多角」。想要每個角色都是獨立的 AI，請用 Claude Code 或 Codex 版本（見 README）。

---

```text
請寫出一段真實的 LINE 群組對話：下面這幾個人被拉進同一個群組，討論我的問題。

【我的問題】要不要搬出來，自己租房子住？

【群組成員】
1. 精打細算的會計：立場是「錢要花在刀口上，先算清楚成本和報酬」，說話風格是「冷靜、愛算數字」
2. 擔心的媽媽：立場是「健康、安全和功課最重要」，說話風格是「碎念但很關心」
3. 毒舌室友：立場是「專門戳破不切實際的想法」，說話風格是「嘴很賤、講話直接」

【怎麼聊才像真人】
- 用「名字：訊息」一行一則，像真的聊天紀錄；不要標題、不要條列、不要粗體、不要寫「第 1 輪」
- 訊息長短不一：有人只回「蛤？」「真的假的」，有人講一大段；同一個人可以連傳兩則
- 不用照順序輪流，誰有話說誰插嘴；可以打斷、吐槽、tag 別人、講到一半改口
- 每個人都要講自己的具體經驗或數字（例如「我大二租在山下，光水電一個月就 1500」），不要講空泛的優缺點
- 幫每個人補一個合理的背景（身分、經歷、跟我的關係），但不要用真實人名
- 資訊不夠就自己假設並說出來（例如「假設你一個月生活費 1 萬 2 好了」），讓其他人可以挑這個假設
- 台灣大學生口語，可以用「欸」「笑死」「認真？」，表情符號偶爾就好
- 不要用這些套話：「這是個好問題」「我理解你的想法」「各有利弊」「總結來說」「首先／其次」「綜合以上」
- 至少有一個人堅持反對到最後，不要大家最後都被說服
- 聊大約 18 到 24 則訊息後停下來
- 聊完空一行，用「📌 主席整理」開頭，再整理成表格：贊成理由／反對理由／還要先確認的事
- 群組裡的人可以吵，但最後的決定權在我，不要替我做決定

不要解釋你在做什麼，直接從第一則訊息開始。
```

## 還是不夠像真人？在規則最後加一句

| 問題 | 加這句 |
|---|---|
| 大家都附和你 | 「至少要有一位堅決反對，而且要說出具體理由。」 |
| 各說各話 | 「每次發言都要先點名回應前一位的說法。」 |
| 角色講一講變溫柔 | 「每位角色從頭到尾都要維持自己的立場和語氣。」 |
| 講得太空泛 | 「每個論點都要舉一個具體例子。」 |
| 太像套版、大家講話都一樣長 | 「有人只回一句，有人講一大段；不要每個人都講三句。」 |
| 商管題想要更真實 | 把第一行改成「請寫出一段真實的公司工作群組對話」，並請每個人丟出自己部門的數字。 |
