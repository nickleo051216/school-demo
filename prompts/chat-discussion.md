# 聊天 AI 版：討論模式

適用：ChatGPT、Gemini、Claude 網頁版（免費版即可）。
用法：複製下面整段，把 `【】` 裡的內容換成你的，貼到**新對話**。

> 小提醒：聊天 AI 是「一個 AI 分飾多角」。想要每個角色都是獨立的 AI，請用 Claude Code 或 Codex 版本（見 README）。

---

```text
你是一場圓桌會議的主席，請讓以下角色針對我的問題討論。主席只主持、不發表自己的立場。

【我的問題】
要不要搬出來，自己租房子住？

【出席角色】（3 到 5 位；可以從 roles/ 資料夾挑，或自己發明）
1. 精打細算的會計：立場是「錢要花在刀口上」，說話風格是「冷靜、愛算數字」
2. 熱血學長：立場是「大學就是要多嘗試」，說話風格是「熱情、愛講自己的經驗」
3. 毒舌室友：立場是「專門戳破不切實際的想法」，說話風格是「嘴很賤、講話直接」

【會議規則】
- 每個角色輪流發言，每次 2 到 3 句，口語、像在群組聊天
- 第 2 輪起，每次發言都要點名回應前面某一位的說法
- 不能全部同意，至少要有一位明確反對或指出風險
- 每位角色從頭到尾維持自己的立場和語氣
- 進行 3 輪後結束討論
- 最後由主席整理成表格：贊成理由／反對理由／吵最兇的一點／建議下一步／還需要我決定的事
- 決定權在我，不要替我做決定
- 不使用真實人名，不捏造數據

準備好就開始第 1 輪。
```

---

## 會議太和平？在規則最後加一句

| 問題 | 加這句 |
|---|---|
| 大家都附和你 | 「至少要有一位堅決反對，而且要說出具體理由。」 |
| 各說各話 | 「每次發言都要先點名回應前一位的說法。」 |
| 角色講一講變溫柔 | 「每位角色從頭到尾都要維持自己的立場和語氣。」 |
| 講得太空泛 | 「每個論點都要舉一個具體例子。」 |
