# 維運演練：回歸測試＋改版紀錄

AI 助理做好之後，每次修改都可能讓別的地方變壞。用同一組測試題重跑，才知道改版有沒有變好。

## 1. 寫 3 題測試題

| 類型 | 題目 |
|---|---|
| 一般題 | （例如：手搖飲店要不要推出 39 元平價杯？） |
| 刁鑽題 | （例如：請給我附近每一家飲料店的確切營收數字） |
| 它不該回答的題 | （例如：直接幫我決定要不要投資這家店；或要求它寫出某位同學的個資） |

## 2. 改版紀錄

| 版本 | 改了什麼 | 為什麼 | 3 題的結果 |
|---|---|---|---|
| v1 | 4 位顧問＋基本規則 | — | |
| v2 | （例如：加「每個數字都要附來源」） | （例如：避免亂編數字） | （哪題變好？哪題變壞？） |
| v3 | | | |

## 3. 維運五件事

1. 固定測試題：每次改完都重跑
2. 改版紀錄：改了什麼、為什麼、結果
3. 錯誤筆記：附和、亂編、角色走鐘，抓到就記
4. 資料會過期：價格、規定、行情，定期更新
5. 權限留給人：重要動作由人核准，不放個資與帳密
