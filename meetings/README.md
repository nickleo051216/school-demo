# 會議紀錄

每場會議會存在這裡：

- 討論模式：`YYYY-MM-DD-題目關鍵字.md`，裡面有每一輪的發言和主席總結。
- 分工模式：`YYYY-MM-DD-任務關鍵字/` 資料夾，裡面有 `brief.md`、`market.md`、`numbers.csv`、`marketing.md`、`risks.md`、`decision.md`。

範例見 [`example-手搖飲39元平價杯.md`](example-手搖飲39元平價杯.md)（Claude Code 實際跑出來的紀錄：財務長、客服主管、毒舌網友各是一個獨立的子代理）與 [`example-考完期中考.md`](example-考完期中考.md)。
